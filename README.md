# 🌸 NyayaSakhi  
**AI Legal Companion for Women**  
*“Clarity in moments of confusion.”*

---

## 🚨 Problem

In critical situations like harassment or abuse, women often feel:
- Confused  
- Overwhelmed  
- Unsure of what to do next  

Even though laws and support systems exist, they are:
- Hard to understand  
- Not accessible in panic moments  
- Lacking immediate guidance  

> The problem is not lack of laws — it’s lack of clarity.

---

## 💡 Solution

**NyayaSakhi** is a mobile-first web application that:

- Helps users **calm down first**
- Understands their situation
- Provides **step-by-step legal guidance**
- Connects them to **emergency support**

---

## 🧭 User Flow

1. 🧘 Calm Screen → Stabilizes the user  
2. 🏠 Dashboard → Simple options  
3. 💬 Chat → Describe the issue  
4. 🧠 Guidance → Clear actionable steps  
5. 🚨 Emergency → Instant help access  

---

## ✨ Key Features

- 💬 Guided Chat Assistant (rule-based AI)
- 🧘 Calm-first experience (unique approach)
- 📚 Simplified Legal Information
- 🚨 Emergency Support (Helplines)
- ⚡ Quick Situations (predefined scenarios)
- 🔒 Privacy-focused design

---

## 🧪 Example Scenario

**User Input:**
> “My roommate is harassing me”

**App Response:**
- Acknowledges emotional stress  
- Identifies issue (mental harassment)  
- Provides clear steps:
  1. Document incidents  
  2. Report to authority  
  3. File formal complaint
